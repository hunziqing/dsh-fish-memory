# 开发文档

当前设计基线是 [独立伴随记忆服务开发方案](./独立伴随记忆服务开发方案.md)。后续实现前应完整阅读，特别是系统边界、上下文修订、情绪时序、归档一致性、接口权限和验收用例。

该方案面向一个用户和一个由 DeepSeek 驱动的角色。独立服务通过 MCP 接入角色聊天程序，保存用户经历与交流习惯，支持持续修订、尘封压缩和自动唤醒。角色主设定与主记忆由原聊天程序管理。

本分支只交付阶段一契约与合成样本；完整方案描述后续目标，不表示运行服务、MCP、模型整理和归档已经实现。后续阶段使用各自分支和 PR。

后续开发约定：

- 将已确认需求、工程契约、可调默认值和待定事项分别处理，不把待定内容当成既定接入条件。
- 同步维护接口、数据迁移、状态机和对应验收用例；行为变更必须说明兼容和恢复策略。
- 原有 DSH 插件继续作为现有系统保留，新增服务不能通过导入插件入口获得隐含的宿主行为。
- 新服务使用独立数据目录，导入器只读原 DSH 文件。
- 当前变更仅涉及文档与 standalone 独立子包，原 DSH 插件代码、依赖与运行配置保持不变。
