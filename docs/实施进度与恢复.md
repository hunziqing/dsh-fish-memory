# 实施进度与恢复

本分支为独立补建的阶段一检查点，只含领域与工具契约、数据库草案、状态守卫、合成样本和 54 项测试。持久服务与后续功能属于其他阶段 PR，不包含在本分支。

远程仓库为 hunziqing/dsh-fish-memory。阶段一分支 codex/companion-phase-1，恢复标签 companion-phase-1-v0.1.0；以远程引用存在为上传成功依据。

每阶段使用独立分支、PR 和恢复标签。阶段二以阶段一分支为 base；前序尚未合并时依次串联，以保证每个 PR 的文件差异仅属于本阶段。不向原作者仓库提交，不自动合并 PR。

此前阶段一、二共同保存过首次检查点。为补齐独立评审，本次从契约及样本产物重建阶段一可单独运行的检查包；既有阶段二、三恢复标签保留，后续以相同源码树衔接新的阶段一祖先，不改写旧恢复点。

个人运行数据不进入 Git。源码标签不替代 SQLite 一致性备份；恢复旧数据时应使用对应版本程序并恢复到新目录。
